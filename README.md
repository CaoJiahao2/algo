# AI 算法求职面试题库

面向 AI 算法求职者的 GitHub 仓库，覆盖**数据结构与算法（DSA）高频题**和 **AI/生成式算法核心题**。每题提供「题目 + 思路 + 复杂度 + 可运行代码 + 测试」。

## 快速开始

```bash
pip install -r requirements.txt
make test
```

## 目录结构

```
algo/
├── dsa/   # 传统数据结构与算法
└── ai/    # AI / 生成式算法
```
